# RouteWise frontend demo
Static design demo: no backend, no build step. Open index.html in a browser.
- index.html: playground (prompt, threshold slider, routing diagram, cost vs quality chart)
- dashboard.html: traffic split, confidence histogram, recent requests
- assets/app.js: simulated router and data (replace score() and the mock rows with real API calls later)
Fonts load from Google Fonts when online; system fonts are used otherwise.
